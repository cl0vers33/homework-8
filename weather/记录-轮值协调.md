# 轮值协调记录（自主实践 · 课堂八）

> 使用说明：每组指定一名协调员（轮值，人人都要当一次），组织一轮讨论并记录四要素。
> 协调员只组织讨论，不替人做决定。**只记录真实发生的讨论，不得虚构。**

## 四要素记录

| 要素 | 内容 |
| --- | --- |
| 议题 | 【当堂填写，例：整合练习中"图表初始化时机"的统一做法——隐藏容器中 init 还是显示时 init】 |
| 参与人 | 【当堂填写全组姓名，注明本轮协调员】 |
| 分歧 | 【当堂填写，例：A 认为 hide 时 init 宽度为 0 图表异常；B 认为 resize 能解决，无需延迟加载】 |
| 结论 | 【当堂填写，例：全组统一采用"首次显示时 init + resize 自适应"，依据是 Console 无报错且截图验证通过】 |

## 讨论过程补充（可选）

- 时间：＿＿＿＿年＿＿月＿＿日 第＿＿节
- 地点 / 线上方式：【填写】
- 关键发言摘要：【填写每人观点一句话】
- 遗留问题：【填写，如无写"无"】

> 四要素（议题 / 参与人 / 分歧 / 结论）缺一不可，是平时大作业三「同伴审查与协调」检查项的直接证据。
