# 昆明天气信息中心

《软件开发综合实践》自主实践作品（课堂八）：个人技术整合练习，作为期末大作业的原型。
主题延续课程六的"昆明天气数据看板"，把前七次课堂成果组装为一个统一入口、数据贯通的综合作品。

## 作品结构与模块衔接

- **页面结构**（课堂一二）：`index.html` 统一入口 + 四模块导航（首页 / 天气查询 / 数据看板 / 三维昆明），当前项高亮
- **样式与响应式**（课堂二三）：Bootstrap 5.3.3 + 自定义 CSS，375 / 768 / 1200px 三档适配
- **交互**（课堂四五）：天气查询按天气状况 / 气温区间 / 关键字即时筛选（事件委托，render 前清空容器）
- **数据**（课堂五六）：`data/weather.json`（课程六数据集），双格式兜底 `data/weather.js`，断网 / 空数据 / 格式错三状态提示
- **可视化**（课堂六）：ECharts 降水量柱状图 + Chart.js 气温折线图（两类图表）
- **三维**（课堂七）：`three-d/scene.html` 昆明城市意象场景（滇池水面、建筑群、西山剪影）

数据衔接：首页摘要（周均最高温 / 降水日数 / 周总降水量）由天气数据实时计算；
查询、看板、摘要共用同一份数据模型，三维场景以"昆明 · 四季如春"呼应天气主题——不是四个孤立页面。

## 运行方法

1. **直接双击 `index.html`**：即可浏览全部功能。
   浏览器在 `file://` 协议下禁止 `fetch` 读取本地 JSON，页面会显示黄色提示条并自动
   切换为 `data/weather.js` 的内置数据（课程六双格式兜底模式），图表照常渲染。
2. **本地服务器（推荐）**：可正常加载 `data/weather.json`，提示条不会出现。

   ```bash
   python -m http.server 8000
   ```

   然后浏览器访问 <http://localhost:8000/>。

三维页从顶部导航「三维昆明」进入，页面上有「返回首页」按钮。

## 技术栈与版本（CDN 均固定版本号，不用 latest）

| 技术 | 版本 | 用途 |
| --- | --- | --- |
| Bootstrap | 5.3.3 | 导航栏、栅格、表单与卡片 |
| jQuery | 3.7.1 | DOM 查询与事件委托 |
| ECharts | 5.5.1 | 降水量柱状图 |
| Chart.js | 4.4.4 | 气温折线图 |
| Three.js | r149 | 三维昆明场景 |

加载顺序：库 CSS → 自定义 CSS；库 JS（jQuery → Bootstrap → ECharts → Chart.js → data/weather.js）→ `app.js`。

## 数据与资源来源

- 天气数据：课程六统一数据集《昆明天气周报（2026年9月6日—12日）》，教学演示数据，非真实统计，
  与 `课程6/昆明天气数据看板/data/weather.json` 完全一致。
- 三维场景：几何体示意模型（滇池、西山为意象表达，非真实地形），建筑名称为虚构城市地标。
- 所有第三方库通过 jsDelivr / cdnjs 公共 CDN 引入，版权归原项目所有。
