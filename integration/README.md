# 迷你版校园公共信息与数据展示中心

《软件开发综合实践》课堂八案例复现作品。按实践指南八第六部分分三步完成，
演示组装路径：页面结构、样式响应式、交互、数据、可视化、三维六个模块的整合。

## 运行方法

本作品支持两种打开方式：

1. **直接双击 `index.html`**：即可浏览全部功能。
   浏览器在 `file://` 协议下会禁止 `fetch` 读取本地 `data.json`，
   页面会显示黄色提示条并自动切换为内置示例数据，图表照常渲染。
2. **本地服务器（推荐）**：可正常加载 `data/data.json`，提示条不会出现。

   ```bash
   python -m http.server 8000
   ```

   然后浏览器访问 <http://localhost:8000/>。

三维导览页从顶部导航「校园三维」进入，页面上有「返回首页」按钮。

## 目录说明

```
integration/
├── index.html          统一入口：导航 + 首页 + 自习室 + 统计三个区块

├── js/app.js           交互逻辑：筛选、数据加载、ECharts 图表
├── data/data.json      自习室使用量统计数据
├── three-d/scene.html  校园三维导览页（Three.js）
├── 自查截图/            质量检查证据截图
└── README.md
```

## 技术栈与版本（CDN 均固定版本号）

| 技术 | 版本 | 用途 |
| --- | --- | --- |
| Bootstrap | 5.3.3 | 导航栏、栅格、表单与卡片 |
| jQuery | 3.7.1 | DOM 查询与事件委托 |
| ECharts | 5.5.1 | 自习室使用量柱状图 |
| Three.js | r149 | 校园三维导览场景 |

加载顺序：库 CSS → 自定义 CSS；库 JS（jQuery → Bootstrap → ECharts）→ `app.js`。

## 数据与资源来源

- 自习室基础信息：教学示例数据，写死在 `js/app.js` 的 `ROOMS` 数组中。
- 使用量统计：教学示例数据，位于 `data/data.json`；加载失败时回退到 `app.js` 内的内置示例数据。
- 三维场景：几何体示意模型，建筑名称为虚构校园地标。
- 所有第三方库通过 jsDelivr / cdnjs 公共 CDN 引入，版权归原项目所有。
